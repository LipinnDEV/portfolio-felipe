## Sobre o projeto

Este portfólio reúne minhas informações, habilidades, experiências e projetos desenvolvidos durante minha jornada na tecnologia. Ele também funciona como um registro da minha evolução na programação: conforme aprendo e construo coisas novas, o site cresce junto.

## O que você encontra no site

- **Apresentação** pessoal
- **Sobre mim**, com minha trajetória e meus objetivos
- **Conhecimentos e tecnologias** que estudo e utilizo
- **Projetos** desenvolvidos, com links para os repositórios
- **Contato**, com os canais para falar comigo

## Como rodar localmente

Pré-requisito: [Node.js](https://nodejs.org/) instalado.

```bash
# clonar o repositório
git clone https://github.com/LipinnDEV/<nome-do-repositorio>.git

# entrar na pasta do projeto
cd <nome-do-repositorio>

# instalar as dependências
npm install

# iniciar o servidor de desenvolvimento
npm run dev
```

Depois, abra o endereço que aparecer no terminal (normalmente `http://localhost:5173`).
